# Saaflok Computers MSP

**Managed IT Services for Business Clients**

A professional, fully responsive website for Saaflok Computers MSP — a managed service provider delivering enterprise-grade IT support, cybersecurity, cloud solutions, and helpdesk services to business clients.

## Features

- **Hero Section** – Value proposition with key stats (99.9% uptime SLA, 24/7 helpdesk, 500+ clients)
- **Services** – Managed IT Support, Cybersecurity, Cloud Solutions, Networking, IT Consulting, Device Management
- **Why Us** – Six core differentiators with icons
- **Pricing** – Three transparent per-seat tiers (Essentials / Business / Enterprise)
- **About** – Company background, stats, and certification/partnership badges
- **Contact Form** – Client enquiry form with validation and feedback
- **Sticky navigation** with mobile-responsive hamburger menu
- **Scroll animations** via Intersection Observer API

## Getting Started

Open `index.html` directly in a browser — no build step required.

## Target Audience

Business clients (SMBs and mid-market enterprises) seeking a reliable managed IT partner.
